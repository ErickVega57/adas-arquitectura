# Instrucciones

En esta actividad implementarás criterios de calidad en el desarrollo de una aplicación de software.

Analicen el juego mazegamesource e incorporen 2 modificaciones para aumentar la calidad del mismo. Deberán cargar un archivo zip que contenga:

- Código fuente.
- Presentación con la explicación de los cambios realizados. Utilizar diagramas UML para presentar el antes y después de las modificaciones del código (diagrama de clases).
- Añadir un escenario de calidad donde se evidencie el beneficio del cambio.
- Integrantes del equipo
- Entrega grupal.

**Formato del archivo:** apellido1apellido2apellido3apellido4.ZIP.

Fecha límite de entrega: 11 de septiembre.
